# 🩺 DocBot – Healthcare Chatbot Web App

DocBot is a simple full-stack web application that provides basic healthcare-related responses through a chatbot interface. It uses a Flask backend and a responsive frontend built with HTML, CSS, and JavaScript.

---

## 🚀 Features

* 💬 Interactive chatbot interface
* ⚡ Real-time communication using Fetch API
* 🧠 Rule-based response system (keyword-based NLP)
* ⏳ Typing animation for realistic chatbot experience
* 📱 Responsive UI with multiple pages (Home, About, Login)

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python (Flask)
* **Communication:** REST API (Fetch)

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/docbot.git
```

### 2. Navigate to project folder

```
cd docbot
```

### 3. Install dependencies

```
pip install -r requirements.txt
```

### 4. Run the Flask server

```
python app.py
```

### 5. Open in browser

```
http://127.0.0.1:5000

```
